# FVG-detektor

Ett Python-script som identifierar Fair Value Gaps (FVG) i historisk prisdata.

## Installation
pip install -r requirements.txt

## Körning
Öppna fvg.ipynb i VS Code eller Jupyter och kör cellerna i ordning.

## Beroenden
- yfinance (hämtar prisdata från Yahoo Finance)
- mplfinance (ritar candlestick-graf med FVG markerat)
